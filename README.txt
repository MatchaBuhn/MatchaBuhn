MATCHABUHN STANDALONE WEBSITE
==============================

This is a standalone HTML/CSS/JavaScript website. It is NOT a Shopify theme.

FILES
-----
index.html   Main website
styles.css   Design and responsive layout
script.js    Products, search, cart, and interactions

TRY IT LOCALLY
--------------
Double-click index.html to preview it in a browser.

IMPORTANT BEFORE LAUNCH
-----------------------
1. Replace YOUR-EMAIL@example.com in script.js with the email address you want contact messages sent to.
2. Replace the sample products in script.js with your real products, prices, descriptions, sizes, and images.
3. Add your real logo/product photos in an assets folder and update the product image markup.
4. Connect a real payment provider/checkout before accepting money. The included cart is functional for browsing and cart management, but checkout is intentionally a demo.
5. Replace the placeholder Privacy/Terms links and add your real shipping/return policies.
6. Buy a domain and upload the files to a web host.

HOSTING
-------
You can upload these files to a static host such as GitHub Pages, Netlify, Vercel, Cloudflare Pages, or traditional web hosting. A custom domain can then point to the host.

For a real store, you will still need a secure checkout/payment provider and a way to manage orders/inventory.
